# AR-0035: Canonical oracle interaction lifecycle

Create the AWG-owned lifecycle contract that makes user interaction explicit
and non-skippable across a project. Define gate types, required artifact
references, task-revision binding, formal-specification review status, and
reconciliation outcomes. Keep private discussion content outside public state;
store typed summaries, digests, and bounded evidence references.

Acceptance requires a formally checked state model, positive and hostile
fixtures, and an explicit mapping consumed by Coordinator AR-0022 and AWQ
AR-0058. The user must review the resulting specification before implementation
ARs may rely on it.
