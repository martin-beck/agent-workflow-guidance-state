# AR-0036: Initial project planning and design review gate

Model the first human/oracle checkpoint after decomposition. Require stable
digests for the work plan, concise design, dependency graph, and AR manifest;
record the user's disposition and explanation context; and block implementation
until the reviewed versions are current. Include rejection and clarification
fixtures and a changed-plan negative case.

The gate must compose with Coordinator's task lifecycle and AWQ's formal,
schema, privacy, and evidence checks.
