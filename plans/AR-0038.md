# AR-0038: Post-discussion reconciliation and reopen loop

Define a deterministic diff and impact analysis over guidance, work plan,
design, specifications, dependency graph, and AR records. Bind each resulting
change to the discussion decision and task revision. Reopen narrowly when
possible, but require a new interaction when contradictions or unresolved
design consequences remain. Preserve prior versions and provenance.

Acceptance requires positive reconciliation plus hostile stale, contradictory,
and silently-continued fixtures.
