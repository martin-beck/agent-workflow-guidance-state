# AR-0042: Discussion persistence and future-point capture

Define the durable session journal and public AR projection. Use atomic,
revision-bound writes and recovery markers; retain private text only in the
approved local boundary while storing a safe summary/digest in public state.
Require a reviewable mapping for every future-discussion request and make
unresolved/re-ask status visible to later sessions.

Acceptance includes interrupted save, duplicate save, stale resume, omitted
free-text request, and request-to-new-AR mapping fixtures.
