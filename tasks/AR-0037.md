This interaction-gate AR defines how the agent presents the issue, candidate
solutions, confidence dimensions, pros/cons, downstream implications,
uncertainties, formal specification, checker limitations, and likely future
effects. The user may select a candidate, reject all, request clarification,
or add an additional solution; an added solution must be evaluated before final
selection.

Formal deliverable: a checked packet/specification-review contract that binds
each item to the exact task revision and records the user's final disposition.
