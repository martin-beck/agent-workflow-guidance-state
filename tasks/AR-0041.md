The agent may batch multiple independent discussion points before opening the
interactive session. Each point has ranked proposals and a concise implication
helper; the user can choose any proposal, reject all, request clarification,
or enter an own proposal. An own proposal is evaluated with the same confidence,
tradeoff, dependency, and formal-specification fields before final selection.
Independent points must not inherit one another's decisions.

Formal deliverable: `specifications/discussion-batching.json` with an
autonomous checker for per-point identity, partial responses, added proposals,
and independent authorization.
