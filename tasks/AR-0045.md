Define the host-facing handoff used when autonomous work reaches a human
decision batch. It must support an inline controllable PTY, an explicitly
configured tmux split, and a copyable manual attach command for SSH/headless
hosts. The contract must never assume that a remote process can open a local
terminal. Session identifiers and attach capabilities must be opaque,
revision-bound, expiry-bounded, and must not contain prompts or private paths.

Acceptance requires a versioned public schema, positive and hostile fixtures,
safe fallback behavior, and documentation of the transport boundary.
